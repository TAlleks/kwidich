  БЫСТРЫЙ СТАРТ: НАСТРОЙКА УЛУЧШЕННОГО ИИ БОТОВ
  5 минут до запуска!
═══════════════════════════════════════════════════════════════════════════════

ШАГ 1: СОЗДАЙТЕ LAYER ДЛЯ БОТОВ (30 секунд)
═══════════════════════════════════════════════════════════════════════════════

1. Edit → Project Settings → Tags and Layers
2. Найдите пустой User Layer (например, Layer 8)
3. Назовите его "Bot"
4. Закройте окно

ШАГ 2: НАЗНАЧЬТЕ LAYER ВСЕМ БОТАМ (1 минута)
═══════════════════════════════════════════════════════════════════════════════

1. В Hierarchy выберите всех ботов (Ctrl+Click)
2. В Inspector вверху найдите "Layer"
3. Выберите "Bot"
4. Если спросит про дочерние объекты - выберите "Yes, change children"

ШАГ 3: НАСТРОЙТЕ ПАРАМЕТРЫ БОТОВ (2 минуты)
═══════════════════════════════════════════════════════════════════════════════

Выберите любого бота в Hierarchy, в Inspector найдите AIPlayer:

ОБЯЗАТЕЛЬНЫЕ НАСТРОЙКИ:

[Avoidance]
botLayer = "Bot"  ← ВАЖНО! Выберите из выпадающего списка

РЕКОМЕНДУЕМЫЕ НАСТРОЙКИ (уже установлены по умолчанию):

[Debug]
debugLogs = true
showGizmos = true

[Team Role]
role = Attacker (или Defender/Support - распределите роли)
roleChangeInterval = 15

[Avoidance]
avoidanceRadius = 5
avoidanceForce = 3
separationWeight = 1.5

[Target Offset]
targetOffsetRadius = 3

[Trajectory Prediction]
usePrediction = true
predictionTime = 1.5

[Push Settings]
pushForce = 15
pushUpwardForce = 5
canPushPlayer = false  ← НЕ МЕНЯЙТЕ! (безопасность)

ШАГ 4: СКОПИРУЙТЕ НАСТРОЙКИ НА ДРУГИХ БОТОВ (1 минута)
═══════════════════════════════════════════════════════════════════════════════

СПОСОБ 1 (быстрый):
1. Выберите настроенного бота
2. В Inspector на компоненте AIPlayer нажмите ⚙ → Copy Component
3. Выберите другого бота
4. На AIPlayer нажмите ⚙ → Paste Component Values
5. Повторите для всех ботов

СПОСОБ 2 (через Prefab):
1. Перетащите настроенного бота в Project (создастся Prefab)
2. Удалите старых ботов
3. Перетащите Prefab на сцену нужное количество раз

ШАГ 5: РАСПРЕДЕЛИТЕ РОЛИ (30 секунд)
═══════════════════════════════════════════════════════════════════════════════

Для лучшего геймплея распределите роли:

Если у вас 6 ботов:
- 3 бота → role = Attacker
- 2 бота → role = Defender
- 1 бот → role = Support

Если у вас 4 бота:
- 2 бота → role = Attacker
- 1 бот → role = Defender
- 1 бот → role = Support

ШАГ 6: ЗАПУСТИТЕ И ПРОТЕСТИРУЙТЕ!
═══════════════════════════════════════════════════════════════════════════════

1. Нажмите Play
2. Откройте Scene View (рядом с Game View)
3. Наблюдайте за Gizmos (желтые сферы, линии, кубики)
4. Проверьте Console на наличие ошибок

ЧЕКЛИСТ ПРОВЕРКИ:

✅ Боты НЕ толпятся в одной точке?
✅ Боты распределяются вокруг мяча?
✅ При краже мяча бот отлетает назад?
✅ В Scene View видны желтые сферы вокруг ботов?
✅ Нет ошибок в Console?

Если все ✅ - ГОТОВО! Наслаждайтесь улучшенным ИИ!

═══════════════════════════════════════════════════════════════════════════════
ЧАСТЫЕ ПРОБЛЕМЫ
═══════════════════════════════════════════════════════════════════════════════

❌ ПРОБЛЕМА: "NullReferenceException: botLayer"
✅ РЕШЕНИЕ: Вы забыли установить botLayer в Inspector!
   → Выберите бота → AIPlayer → Avoidance → botLayer = "Bot"

❌ ПРОБЛЕМА: Боты все еще толпятся
✅ РЕШЕНИЕ: Увеличьте параметры избегания
   → avoidanceRadius = 7
   → avoidanceForce = 5
   → targetOffsetRadius = 5

❌ ПРОБЛЕМА: Боты летают хаотично
✅ РЕШЕНИЕ: Уменьшите параметры избегания
   → avoidanceRadius = 3
   → avoidanceForce = 2

❌ ПРОБЛЕМА: Gizmos не видны в Scene View
✅ РЕШЕНИЕ: Включите Gizmos
   → В Scene View вверху справа найдите кнопку "Gizmos"
   → Убедитесь что она включена

❌ ПРОБЛЕМА: Толчок слишком сильный
✅ РЕШЕНИЕ: Уменьшите силу толчка
   → pushForce = 10
   → pushUpwardForce = 3

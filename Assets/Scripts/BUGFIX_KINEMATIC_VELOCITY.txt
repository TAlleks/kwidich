================================================================================
ИСПРАВЛЕНИЕ ОШИБКИ: "Setting linear velocity of a kinematic body"
================================================================================
Дата: 30 марта 2026
Версия: 1.1

================================================================================
ОПИСАНИЕ ПРОБЛЕМЫ
================================================================================

ОШИБКА:
Setting linear velocity of a kinematic body is not supported.
UnityEngine.Rigidbody:set_linearVelocity (UnityEngine.Vector3)
Quaffle:TryChangeOwner (UnityEngine.Transform,bool) (at Assets/Scripts/QuaffleController.cs:107)
AIPlayer:StealBallFromBot (AIPlayer) (at Assets/Scripts/PlayerController.cs:753)
AIPlayer:CheckActions () (at Assets/Scripts/PlayerController.cs:691)
AIPlayer:FixedUpdate () (at Assets/Scripts/PlayerController.cs:234)

ПРИЧИНА:
В методе TryChangeOwner() класса Quaffle мы пытались установить linearVelocity
и angularVelocity ДО того, как установили rb.isKinematic = true.

В Unity нельзя изменять velocity у kinematic тела, поэтому возникала ошибка.

НЕПРАВИЛЬНЫЙ ПОРЯДОК (ДО ИСПРАВЛЕНИЯ):
1. rb.linearVelocity = Vector3.zero;   // ❌ Ошибка! Тело еще не kinematic
2. rb.angularVelocity = Vector3.zero;  // ❌ Ошибка! Тело еще не kinematic
3. rb.isKinematic = true;              // Только здесь делаем kinematic
4. rb.useGravity = false;

================================================================================
РЕШЕНИЕ
================================================================================

ПРАВИЛЬНЫЙ ПОРЯДОК (ПОСЛЕ ИСПРАВЛЕНИЯ):
1. rb.isKinematic = true;              // ✅ Сначала делаем kinematic
2. rb.useGravity = false;              // ✅ Отключаем гравитацию
3. (velocity не трогаем)               // ✅ Kinematic тела игнорируют физику

ОБОСНОВАНИЕ:
Kinematic тела в Unity не используют физику симуляции, поэтому:
- Не нужно обнулять velocity
- Не нужно обнулять angularVelocity
- Они просто игнорируют эти значения

ФАЙЛ: QuaffleController.cs

```csharp

isHeld = true;

// ИСПРАВЛЕНО: Сначала делаем kinematic, потом отключаем коллайдер
// Для kinematic тела не нужно обнулять velocity - оно игнорирует физику
rb.isKinematic = true;
rb.useGravity = false;
col.gameObject.SetActive(false);
```

================================================================================
ЗАМЕТКИ ДЛЯ РАЗРАБОТЧИКОВ
================================================================================

ВАЖНО ПОМНИТЬ:
- Kinematic тела НЕ участвуют в физической симуляции
- Нельзя изменять velocity/angularVelocity у kinematic тел
- Нельзя применять силы (AddForce) к kinematic телам
- Kinematic тела двигаются только через transform.position или rb.MovePosition()

ПРАВИЛЬНЫЙ ПОРЯДОК ПРИ СМЕНЕ РЕЖИМА:

При переходе в kinematic режим:
1. rb.isKinematic = true;
2. rb.useGravity = false;
3. (не трогаем velocity)

При переходе из kinematic режима:
1. rb.isKinematic = false;
2. rb.useGravity = true;
3. rb.linearVelocity = Vector3.zero; (теперь можно)
4. rb.AddForce(...) (теперь можно)

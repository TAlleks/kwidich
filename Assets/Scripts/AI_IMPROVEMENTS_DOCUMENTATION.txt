1. СИСТЕМА ИЗБЕГАНИЯ СТОЛКНОВЕНИЙ (AVOIDANCE)
═══════════════════════════════════════════════════════════════════════════════

ПРОБЛЕМА (ДО):
- Все боты летели в одну точку
- Толпились друг на друге
- Вылетали вертикально из-за коллизий

РЕШЕНИЕ (ПОСЛЕ):
- Боты обнаруживают других ботов в радиусе
- Автоматически отталкиваются друг от друга
- Летят к цели с учетом окружения

ПАРАМЕТРЫ В INSPECTOR:

[Avoidance]
- avoidanceRadius = 5f          // Радиус обнаружения других ботов
- avoidanceForce = 3f            // Сила отталкивания
- separationWeight = 1.5f        // Множитель силы разделения
- botLayer                       // LayerMask для обнаружения ботов

КАК НАСТРОИТЬ:

1. Создайте новый Layer "Bot" (Edit → Project Settings → Tags and Layers)
2. Назначьте всем ботам Layer "Bot"
3. В Inspector бота установите botLayer = "Bot"
4. Настройте параметры:
   - avoidanceRadius: 5-7 для плотной толпы, 3-4 для разреженной
   - avoidanceForce: 2-4 (чем больше, тем сильнее отталкивание)
   - separationWeight: 1.0-2.0 (множитель эффекта)

ТЕХНИЧЕСКИЕ ДЕТАЛИ:

Метод CalculateAvoidance():
- Использует Physics.OverlapSphere для поиска ботов
- Вычисляет вектор отталкивания от каждого бота
- Чем ближе бот, тем сильнее отталкивание (1/distance)
- Усредняет все векторы и применяет вес

Формула:
avoidanceVector = Σ(diff.normalized / distance) / count * separationWeight

2. СИСТЕМА ФИЗИЧЕСКОГО ТОЛЧКА
═══════════════════════════════════════════════════════════════════════════════

ОПИСАНИЕ:
При краже мяча бот/игрок физически толкает цель с заданной силой.

ПАРАМЕТРЫ В INSPECTOR:

[Push Settings]
- pushForce = 15f                // Сила толчка (горизонтальная)
- pushUpwardForce = 5f           // Вертикальная составляющая
- canPushPlayer = false          // Может ли бот толкать игрока

⚠️ ВАЖНО: canPushPlayer = false по умолчанию!
Это защищает игрока в мехатронной капсуле от сильных толчков.

ПОВЕДЕНИЕ:

1. БОТ КРАДЕТ У БОТА:
   - Толчок ВСЕГДА применяется
   - Сила: pushForce (15 по умолчанию)
   - Направление: от атакующего к цели + вверх

2. БОТ КРАДЕТ У ИГРОКА:
   - Толчок применяется ТОЛЬКО если canPushPlayer = true
   - Если false: мяч крадется БЕЗ толчка (безопасный режим)
   - Лог: "Украл мяч у игрока БЕЗ толчка (безопасный режим)"

3. ИГРОК КРАДЕТ У БОТА:
   - Толчок ВСЕГДА применяется
   - Сила настраивается в FuturiftMoving/BroomController
   - Параметры: pushForce, pushUpwardForce

КАК НАСТРОИТЬ СИЛУ ТОЛЧКА:

Слабый толчок (мягкий):
- pushForce = 8-10
- pushUpwardForce = 2-3

Средний толчок (по умолчанию):
- pushForce = 15
- pushUpwardForce = 5

Сильный толчок (агрессивный):
- pushForce = 20-25
- pushUpwardForce = 7-10

ФОРМУЛА ТОЛЧКА:

Vector3 pushDirection = (target.position - attacker.position).normalized;
pushDirection.y = pushUpwardForce / pushForce;
target.rb.AddForce(pushDirection * pushForce, ForceMode.Impulse);

3. СИСТЕМА РОЛЕЙ (ATTACKER/DEFENDER/SUPPORT)
═══════════════════════════════════════════════════════════════════════════════

ОПИСАНИЕ:
Боты имеют разные роли, определяющие их поведение.

РОЛИ:

1. ATTACKER (Атакующий)
   - Агрессивно преследует мяч
   - Первым идет за свободным мячом
   - Активно крадет у противников
   - Лучший выбор для нападения

2. DEFENDER (Защитник)
   - Защищает свои ворота
   - Перехватывает противников с мячом
   - Приоритет: враги с мячом > свободный мяч
   - Лучший выбор для обороны

3. SUPPORT (Поддержка)
   - Занимает стратегические позиции
   - Подбирает свободные мячи
   - Следит за игроком
   - Универсальная роль

ПАРАМЕТРЫ В INSPECTOR:

[Team Role]
- role = Attacker                // Текущая роль бота
- roleChangeInterval = 15f       // Интервал смены роли (секунды)

АВТОМАТИЧЕСКАЯ СМЕНА РОЛЕЙ:

Боты автоматически меняют роль каждые roleChangeInterval секунд.
Это добавляет разнообразие и непредсказуемость.

Чтобы отключить автоматическую смену:
- Установите roleChangeInterval = 999999

Чтобы зафиксировать роль:
- Установите нужную роль в Inspector
- Установите roleChangeInterval = 999999

РЕКОМЕНДАЦИИ ПО РАСПРЕДЕЛЕНИЮ:

Для команды из 6 ботов:
- 3 Attacker (50%)
- 2 Defender (33%)
- 1 Support (17%)

Для команды из 4 ботов:
- 2 Attacker
- 1 Defender
- 1 Support

4. ПРЕДСКАЗАНИЕ ТРАЕКТОРИИ МЯЧА
═══════════════════════════════════════════════════════════════════════════════

ОПИСАНИЕ:
Боты предсказывают, где будет мяч через N секунд, и летят к этой точке.

ПАРАМЕТРЫ В INSPECTOR:

[Trajectory Prediction]
- usePrediction = true           // Включить предсказание
- predictionTime = 1.5f          // Время предсказания (секунды)

КАК ЭТО РАБОТАЕТ:

1. Бот обнаруживает летящий мяч
2. Вычисляет его скорость и направление
3. Применяет физическую формулу с гравитацией
4. Летит к предсказанной точке перехвата

ФОРМУЛА:

predictedPos = ballPos + velocity * time + 0.5 * gravity * time²

НАСТРОЙКА:

Быстрая реакция (ближний перехват):
- predictionTime = 0.5-1.0

Средняя реакция (по умолчанию):
- predictionTime = 1.5

Дальний перехват:
- predictionTime = 2.0-3.0

⚠️ ВНИМАНИЕ:
Слишком большое predictionTime может привести к ошибкам,
так как мяч может столкнуться с препятствием.

ВИЗУАЛИЗАЦИЯ:

При showGizmos = true в Scene View видна:
- Текущая позиция мяча (красная линия)
- Предсказанная позиция (фиолетовая сфера)
- Линия траектории (фиолетовая)

5. ДИНАМИЧЕСКАЯ СКОРОСТЬ
═══════════════════════════════════════════════════════════════════════════════

ОПИСАНИЕ:
Скорость бота автоматически меняется в зависимости от ситуации.

ФАКТОРЫ ВЛИЯНИЯ:

1. РАССТОЯНИЕ ДО ЦЕЛИ:
   - Далеко (>20m): скорость × 1.3 (буст)
   - Близко (<3m): скорость × (distance/3) (замедление)
   - Средне: базовая скорость

2. ПЛОТНОСТЬ ТОЛПЫ:
   - Много ботов рядом (>3): скорость × 0.7 (замедление)
   - Мало ботов: базовая скорость

3. ЦЕЛЬ - ВОРОТА:
   - При приближении к воротам: плавное замедление
   - Остановка на stopDistanceFromGoal

БАЗОВАЯ СКОРОСТЬ:

[Settings]
- moveSpeed = 15f                // Базовая скорость движения

ПРИМЕРЫ:

Ситуация 1: Бот далеко от мяча, один
→ Скорость = 15 × 1.3 = 19.5 (быстро летит)

Ситуация 2: Бот в толпе (5 ботов рядом)
→ Скорость = 15 × 0.7 = 10.5 (медленно, избегает столкновений)

Ситуация 3: Бот близко к мячу (2m), один
→ Скорость = 15 × (2/3) = 10 (замедляется для точного подбора)

6. СИСТЕМА OFFSET (РАЗБРОС ВОКРУГ ЦЕЛИ)
═══════════════════════════════════════════════════════════════════════════════

ОПИСАНИЕ:
Боты летят не точно к мячу, а к случайной точке вокруг него.

ПАРАМЕТРЫ В INSPECTOR:

[Target Offset]
- targetOffsetRadius = 3f        // Радиус разброса вокруг цели

КАК ЭТО РАБОТАЕТ:

1. Бот выбирает цель (мяч)
2. Генерируется случайный offset в радиусе targetOffsetRadius
3. Бот летит к (позиция мяча + offset)
4. При выборе новой цели генерируется новый offset

РЕЗУЛЬТАТ:
- Боты не толпятся в одной точке
- Распределяются вокруг мяча
- Более реалистичное поведение

НАСТРОЙКА:

Плотная группа:
- targetOffsetRadius = 1-2

Средняя группа (по умолчанию):
- targetOffsetRadius = 3

Разреженная группа:
- targetOffsetRadius = 4-5

⚠️ ПРИМЕЧАНИЕ:
Offset НЕ применяется к воротам (боты летят точно к воротам).

7. ВИЗУАЛЬНАЯ ОТЛАДКА (GIZMOS)
═══════════════════════════════════════════════════════════════════════════════

ОПИСАНИЕ:
Визуализация поведения ботов в Scene View для отладки.

ПАРАМЕТРЫ В INSPECTOR:

[Debug]
- debugLogs = true               // Логи в Console
- showGizmos = true              // Визуализация в Scene View

ЧТО ПОКАЗЫВАЕТСЯ:

1. ЖЕЛТАЯ СФЕРА:
   - Радиус избегания (avoidanceRadius)
   - Показывает зону обнаружения других ботов

2. КРАСНАЯ/ЗЕЛЕНАЯ ЛИНИЯ:
   - Красная: бот БЕЗ мяча, летит к цели
   - Зеленая: бот С мячом, летит к воротам

3. ГОЛУБАЯ СФЕРА:
   - Целевая позиция с offset
   - Показывает, куда именно летит бот

4. ФИОЛЕТОВАЯ СФЕРА + ЛИНИЯ:
   - Предсказанная позиция мяча
   - Траектория предсказания

5. ЦВЕТНОЙ КУБ НАД БОТОМ:
   - Красный: Attacker
   - Синий: Defender
   - Желтый: Support

КАК ИСПОЛЬЗОВАТЬ:

1. Запустите игру в Unity Editor
2. Откройте Scene View (рядом с Game View)
3. Наблюдайте за визуализацией
4. Настраивайте параметры в реальном времени

СОВЕТЫ ПО ОТЛАДКЕ:

Проблема: Боты толпятся
→ Проверьте желтые сферы (avoidanceRadius)
→ Увеличьте avoidanceRadius или avoidanceForce

Проблема: Боты летят мимо мяча
→ Проверьте голубые сферы (offset)
→ Уменьшите targetOffsetRadius

Проблема: Боты не перехватывают мяч
→ Проверьте фиолетовые сферы (prediction)
→ Настройте predictionTime

3. Если включаете, уменьшите pushForce до 5-8
4. Предупредите игрока о возможных толчках

Вместо физического толчка можно:
- Визуальный эффект (вспышка, тряска камеры)
- Звуковой эффект
- Вибрация контроллера
- Замедление игрока на 1-2 секунды

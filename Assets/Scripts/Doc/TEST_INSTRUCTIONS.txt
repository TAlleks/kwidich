2. ПРОВЕРЬТЕ ОШИБКИ КОМПИЛЯЦИИ
   - Откройте Console (Window → General → Console)
   - Убедитесь, что нет ошибок (красных сообщений)
   - Если есть ошибки - сообщите мне

3. ДОБАВЬТЕ ТЕСТОВЫЙ СКРИПТ НА СЦЕНУ
   - Создайте пустой GameObject (GameObject → Create Empty)
   - Назовите его "OptimizationTest"
   - Добавьте скрипт OptimizationTest.cs на этот объект
   - Запустите игру (Play)

4. ПРОВЕРЬТЕ РЕЗУЛЬТАТЫ ТЕСТА
   - В левом верхнем углу появится окно с результатами
   - Все тесты должны быть ✓ PASSED
   - В Console будет детальный лог

5. ТЕСТИРОВАНИЕ ГЕЙМПЛЕЯ
   a) Подбор мяча игроком:
      - Подлетите к мячу
      - Мяч должен автоматически подобраться
   
   b) Кража мяча ботом у игрока:
      - Возьмите мяч
      - Подлетите к боту
      - Бот должен украсть мяч
   
   c) Кража мяча игроком у бота:
      - Дождитесь, пока бот возьмет мяч
      - Подлетите к боту
      - Вы должны украсть мяч
   
   d) Поведение ботов:
      - Боты должны искать мяч
      - Боты должны лететь к воротам с мячом
      - Боты должны бросать мяч в ворота

6. ПРОВЕРКА ПРОИЗВОДИТЕЛЬНОСТИ
   - Откройте Stats (Window → Analysis → Stats)
   - Проверьте FPS (должен быть выше, чем раньше)
   - Добавьте больше ботов на сцену для стресс-теста

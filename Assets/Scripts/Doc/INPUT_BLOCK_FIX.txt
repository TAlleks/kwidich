ОПИСАНИЕ:
Если игрок двигается (нажимает кнопки управления) после забитого гола,
телепортация на стартовую позицию не работает. Игрок остается на месте.

Однако, если не нажимать никаких кнопок, телепортация работает корректно.

ПРИЧИНА:
1. RespawnToStartPosition() телепортирует игрока на стартовую позицию
2. Но в том же кадре или следующем кадре Update() обрабатывает input
3. HandleInput() и ApplyMovement() перезаписывают позицию игрока
4. В результате игрок остается на месте или двигается по инерции

ТЕХНИЧЕСКАЯ ПРИЧИНА:
- Телепортация: transform.SetPositionAndRotation() в RespawnToStartPosition()
- Input обработка: HandleInput() в Update() каждый кадр
- Движение: ApplyMovement() в FixedUpdate() каждый физический кадр
- Input перезаписывает результат телепортации

РЕШЕНИЕ

ДОБАВЛЕНА БЛОКИРОВКА УПРАВЛЕНИЯ:

1. Добавлен флаг isInputDisabled (bool)
   - По умолчанию false (управление активно)
   - Устанавливается в true при респавне
   - Блокирует обработку input и движения

2. Изменен Update():
   - Проверяет isInputDisabled перед обработкой input
   - Если заблокировано - пропускает HandleInput(), CheckGround(), UpdateSteering(), etc.

3. Изменен FixedUpdate():
   - Проверяет isInputDisabled перед применением движения
   - Если заблокировано - пропускает ApplyMovement(), ApplyHeightControl()

4. Добавлена корутина EnableInputAfterDelay():
   - Ждет 0.1 секунды после телепортации
   - Разблокирует управление (isInputDisabled = false)
   - Игрок может снова управлять персонажем

ПОСЛЕДОВАТЕЛЬНОСТЬ:
1. Гол забит → начинается празднование
2. Через 2.5 сек вызывается RespawnToStartPosition()
3. isInputDisabled = true (управление заблокировано)
4. Телепортация на стартовую позицию
5. Обнуление физики (velocity, angularVelocity)
6. Запуск корутины EnableInputAfterDelay(0.1f)
7. Ожидание 0.1 секунды
8. isInputDisabled = false (управление разблокировано)
9. Игрок может снова управлять персонажем

```csharp
{
    // Если управление заблокировано - не обрабатываем input
    if (!isInputDisabled)
    {
        HandleInput();
        CheckGround();
        UpdateSteering();
        HandleCollisionRecovery();  // Только в BroomController
        ThrowBallInput();
        TryStealBall();
    }
    
    // Проверка синхронизации мяча (всегда выполняется)
    // ...

```

ИЗМЕНЕН FIXEDUPDATE():
```csharp
void FixedUpdate()
{
    // Если управление заблокировано - не применяем движение
    if (!isInputDisabled)
    {
        ApplyMovement();
        ApplyHeightControl();
    }
}
```

ИЗМЕНЕН RESPAWNTOSTARPOSITION():
```csharp
public void RespawnToStartPosition()
{
    // Блокируем управление
    isInputDisabled = true;
    
    // Сбрасываем мяч если есть
    if (hasBall && quaffle != null)
    {
        SetHasBall(false, null);
    }
    
    // Телепортируем на стартовую позицию
    transform.SetPositionAndRotation(startPosition, startRotation);
    
    // Обнуляем физику
    rb.linearVelocity = Vector3.zero;
    rb.angularVelocity = Vector3.zero;
    
    // Сбрасываем скорость и передачу (BroomController)
    currentSpeed = 0f;
    currentGear = 0;  // Только в BroomController
    
    // Сбрасываем направление полета
    flightDirection = transform.forward;
    
    // Разблокируем управление через небольшую задержку
    StartCoroutine(EnableInputAfterDelay(0.1f));
    
    Debug.Log("[Controller] Респавн на стартовую позицию");
}
```

ДОБАВЛЕНА КОРУТИНА:
```csharp
/// <summary>
/// Разблокировка управления после задержки
/// </summary>
private System.Collections.IEnumerator EnableInputAfterDelay(float delay)
{
    yield return new WaitForSeconds(delay);
    isInputDisabled = false;
    Debug.Log("[Controller] Управление разблокировано");
}
```

ТЕСТИРОВАНИЕ

СЦЕНАРИЙ 1: Респавн с нажатыми кнопками
1. Начните игру
2. Забейте гол
3. ВО ВРЕМЯ ПРАЗДНОВАНИЯ нажимайте кнопки управления (W, A, S, D или стики)
4. Проверьте:
   ✅ После празднования игрок телепортируется на стартовую позицию
   ✅ Игрок НЕ двигается во время телепортации
   ✅ Через 0.1 сек управление восстанавливается
   ✅ Игрок может снова управлять персонажем

СЦЕНАРИЙ 2: Респавн без нажатых кнопок
1. Начните игру
2. Забейте гол
3. НЕ нажимайте никаких кнопок
4. Проверьте:
   ✅ После празднования игрок телепортируется на стартовую позицию
   ✅ Управление восстанавливается через 0.1 сек
   ✅ Все работает как и раньше

СЦЕНАРИЙ 3: Множественные голы
1. Забейте несколько голов подряд
2. Каждый раз нажимайте кнопки во время празднования
3. Проверьте:
   ✅ Каждый раз телепортация работает корректно
   ✅ Управление каждый раз восстанавливается
   ✅ Нет накопления ошибок

================================================================================
ТЕХНИЧЕСКИЕ ДЕТАЛИ
================================================================================

ПОЧЕМУ 0.1 СЕКУНДЫ ЗАДЕРЖКИ:
- Достаточно для завершения телепортации
- Достаточно для обнуления физики
- Незаметно для игрока (очень короткая задержка)
- Предотвращает конфликт между телепортацией и input

АЛЬТЕРНАТИВНЫЕ РЕШЕНИЯ (НЕ ИСПОЛЬЗОВАНЫ):
1. Отключение Rigidbody.isKinematic
   - Слишком сложно, может вызвать другие проблемы
2. Обнуление input вручную
   - Не работает для всех типов input (клавиатура, геймпад, VR)
3. Увеличение задержки до 0.5 сек
   - Слишком заметно для игрока, ухудшает UX

ВЫБРАННОЕ РЕШЕНИЕ:
- Простое и надежное
- Работает для всех типов input
- Минимальная задержка (0.1 сек)
- Не влияет на другие системы

================================================================================
ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
================================================================================

- Задержка 0.1 секунды перед восстановлением управления

- Если игрок держит кнопку нажатой, после разблокировки он сразу начнет двигаться
  (это нормальное поведение)

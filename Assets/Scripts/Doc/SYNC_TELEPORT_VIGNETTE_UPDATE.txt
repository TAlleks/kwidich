3. НОВЫЙ ФАЙЛ: VIGNETTECONTROLLER.CS
================================================================================

ОПИСАНИЕ:
Контроллер для управления Vignette эффектом через URP (Universal Render Pipeline).

ОСНОВНЫЕ МЕТОДЫ:
- PlayTeleportEffect(Action onTeleport) - воспроизводит эффект телепортации
- FadeVignette(from, to, duration) - плавное изменение интенсивности
- ResetVignette() - сброс в начальное состояние

ПАРАМЕТРЫ:
- postProcessVolume (Volume) - Global Volume с Vignette Override
- fadeDuration (0.3 сек) - длительность fade-in/fade-out
- maxIntensity (0.8) - максимальная интенсивность затемнения

ПОСЛЕДОВАТЕЛЬНОСТЬ:
1. Fade-out: intensity 0 → 0.8 (0.3 сек)
2. Callback: телепортация всех
3. Fade-in: intensity 0.8 → 0 (0.3 сек)

================================================================================
4. ИЗМЕНЕНИЯ В PLAYERCONTROLLER.CS
================================================================================

ДОБАВЛЕН МЕТОД:
- SlowdownSequence() - плавное замедление бота БЕЗ телепортации

ЛОГИКА:
- Замедление 0.5 секунды
- Плавная интерполяция velocity → 0
- Используется для синхронной телепортации

КОД:
```csharp
public IEnumerator SlowdownSequence()
{
    float slowdownDuration = 0.5f;
    float elapsed = 0f;
    Vector3 initialVelocity = rb.linearVelocity;
    
    while (elapsed < slowdownDuration)
    {
        elapsed += Time.deltaTime;
        float t = elapsed / slowdownDuration;
        
        rb.linearVelocity = Vector3.Lerp(initialVelocity, Vector3.zero, t);
        rb.angularVelocity = Vector3.Lerp(rb.angularVelocity, Vector3.zero, t);
        
        yield return null;
    }
    
    rb.linearVelocity = Vector3.zero;
    rb.angularVelocity = Vector3.zero;
}
```

7. ИЗМЕНЕНИЯ В GAMESCOREMANAGER.CS
================================================================================

ДОБАВЛЕНО ПОЛЕ:
```csharp
[Header("Visual Effects")]
public VignetteController vignetteController;
```

ИЗМЕНЕН МЕТОД HandleGoalSequence():

НОВАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ:
```csharp
// 1-5. Празднование, респавн мяча (без изменений)

// 6. Запускаем замедление ВСЕХ
StartCoroutine(player.SlowdownSequence());
foreach (var bot in allBots)
    StartCoroutine(bot.SlowdownSequence());

// 7. Ждем окончания замедления
yield return new WaitForSeconds(0.5f);

// 8. Vignette эффект + одновременная телепортация
yield return vignetteController.PlayTeleportEffect(() =>
{
    player.TeleportToStart();
    foreach (var bot in allBots)
        bot.TeleportToStartPosition();
});

// 9. Звук респавна

// 10. Разблокировка управления игрока
player.EnableInput();
```

FALLBACK:
Если VignetteController не назначен - телепортация без эффекта (с предупреждением).

================================================================================
8. НАСТРОЙКА В UNITY (ОБЯЗАТЕЛЬНО!)
================================================================================

### ШАГ 1: СОЗДАТЬ GLOBAL VOLUME

1. В иерархии: GameObject → Volume → Global Volume
2. Назовите его "Global Volume"
3. В Inspector найдите компонент "Volume"
4. Нажмите "New" рядом с Profile (создаст новый профиль)
5. Нажмите "Add Override" → Post-processing → Vignette
6. В Vignette Override:
   - Включите галочку "Intensity"
   - Установите Intensity = 0
   - Включите галочку "Smoothness" (опционально)
   - Установите Smoothness = 0.4 (опционально)

### ШАГ 2: СОЗДАТЬ VIGNETTECONTROLLER

1. Создайте пустой GameObject: GameObject → Create Empty
2. Назовите его "VignetteController"
3. Добавьте скрипт VignetteController (Add Component → VignetteController)
4. В Inspector:
   - Перетащите "Global Volume" в поле "Post Process Volume"
   - Установите "Fade Duration" = 0.3
   - Установите "Max Intensity" = 0.8

### ШАГ 3: НАСТРОИТЬ GAMESCOREMANAGER

1. Найдите GameScoreManager в сцене
2. В Inspector найдите раздел "Visual Effects"
3. Перетащите "VignetteController" в поле "Vignette Controller"

### ШАГ 4: ПРОВЕРИТЬ URP НАСТРОЙКИ

1. Откройте Project Settings (Edit → Project Settings)
2. Перейдите в Graphics
3. Убедитесь, что используется URP Asset
4. Откройте URP Asset (двойной клик)
5. Убедитесь, что "Post Processing" включен
6. Выберите Main Camera в сцене
7. В Inspector найдите компонент "Camera"
8. Убедитесь, что "Post Processing" включен

### ШАГ 5: ПРОВЕРИТЬ ОСТАЛЬНЫЕ НАСТРОЙКИ

1. GameScoreManager:
   - ballRespawnPosition установлен (например, Vector3(0, 5, 0))
   - (Опционально) respawnSound назначен
   - (Опционально) audioSource назначен

2. GoalRing (для каждых ворот):
   - Fire объект назначен
   - fireActiveDuration = 2.5

================================================================================
14. TROUBLESHOOTING
================================================================================

### Vignette не работает:
1. Проверьте, что используется URP (Project Settings → Graphics)
2. Проверьте, что Post-Processing включен в URP Asset
3. Проверьте, что Post-Processing включен на камере
4. Проверьте, что Vignette Override добавлен в Volume Profile
5. Проверьте, что VignetteController назначен в GameScoreManager

### Телепортация не синхронная:
1. Проверьте, что все методы SlowdownSequence() вызываются
2. Проверьте, что ожидание 0.5 секунды присутствует
3. Проверьте Console на ошибки

### Управление не восстанавливается:
1. Проверьте, что player.EnableInput() вызывается
2. Проверьте, что isInputDisabled сбрасывается в false

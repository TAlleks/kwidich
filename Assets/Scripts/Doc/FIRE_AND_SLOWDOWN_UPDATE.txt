1. ЭФФЕКТ ОГНЯ В GOALRING
================================================================================

ОПИСАНИЕ:
При забитом голе объект Fire включается на 2.5 секунды, затем автоматически
выключается.

РЕАЛИЗАЦИЯ:

Добавлено в GoalRing.cs:
- Поле: [SerializeField] private GameObject Fire
- Поле: [SerializeField] private float fireActiveDuration = 2.5f
- Метод: ActivateFireEffect() - корутина для управления эффектом
- В Awake(): Fire.SetActive(false) - отключаем при старте
- В OnTriggerEnter(): StartCoroutine(ActivateFireEffect()) - включаем при голе

ПОСЛЕДОВАТЕЛЬНОСТЬ:
1. Мяч попадает в ворота
2. Звук гола воспроизводится
3. Fire.SetActive(true) - эффект огня включается
4. Ожидание 2.5 секунды
5. Fire.SetActive(false) - эффект огня выключается

НАСТРОЙКА В UNITY:
1. Откройте GoalRing в Inspector
2. Найдите поле "Fire" в разделе "Visual Effects"
3. Перетащите объект Fire из иерархии в это поле
4. (Опционально) Измените fireActiveDuration (по умолчанию 2.5 сек)

ВАЖНО:
- Объект Fire должен быть дочерним объектом GoalRing или находиться в сцене
- Fire должен иметь компоненты для визуального эффекта (ParticleSystem, Light, и т.д.)
- Fire будет автоматически выключен при старте игры

================================================================================
2. ПЛАВНОЕ ЗАМЕДЛЕНИЕ ИГРОКА ПРИ РЕСПАВНЕ
================================================================================

ПРОБЛЕМА:
Раньше игрок мгновенно блокировался и телепортировался. Это выглядело резко
и неестественно.

РЕШЕНИЕ:
Добавлена плавная последовательность респавна:

НОВАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ:
1. Блокировка управления (isInputDisabled = true)
2. Сброс мяча (если есть)
3. **ПЛАВНОЕ ЗАМЕДЛЕНИЕ (0.5 секунды)**
   - Velocity плавно уменьшается до нуля
   - AngularVelocity плавно уменьшается до нуля
   - CurrentSpeed плавно уменьшается до нуля
   - Используется Lerp с ease-out эффектом
4. Полная остановка (все velocity = 0)
5. Пауза 0.1 секунды
6. **ТЕЛЕПОРТАЦИЯ** на стартовую позицию
7. Пауза 0.1 секунды
8. Разблокировка управления (isInputDisabled = false)

ТЕХНИЧЕСКИЕ ДЕТАЛИ:

Добавлена корутина RespawnSequence():
```csharp
private IEnumerator RespawnSequence()
{
    // 1. Блокируем управление
    isInputDisabled = true;
    
    // 2. Сбрасываем мяч
    if (hasBall && quaffle != null)
        SetHasBall(false, null);
    
    // 3. Плавное замедление (0.5 сек)
    float slowdownDuration = 0.5f;
    float elapsed = 0f;
    Vector3 initialVelocity = rb.linearVelocity;
    
    while (elapsed < slowdownDuration)
    {
        elapsed += Time.deltaTime;
        float t = elapsed / slowdownDuration;
        
        // Плавное замедление (ease-out)
        rb.linearVelocity = Vector3.Lerp(initialVelocity, Vector3.zero, t);
        rb.angularVelocity = Vector3.Lerp(rb.angularVelocity, Vector3.zero, t);
        currentSpeed = Mathf.Lerp(currentSpeed, 0f, t);
        
        yield return null;
    }
    
    // 4. Полная остановка
    rb.linearVelocity = Vector3.zero;
    rb.angularVelocity = Vector3.zero;
    currentSpeed = 0f;
    
    // 5. Пауза перед телепортацией
    yield return new WaitForSeconds(0.1f);
    
    // 6. Телепортация
    transform.SetPositionAndRotation(startPosition, startRotation);
    flightDirection = transform.forward;
    
    // 7. Пауза после телепортации
    yield return new WaitForSeconds(0.1f);
    
    // 8. Разблокировка управления
    isInputDisabled = false;
}
```

ПРЕИМУЩЕСТВА:
✅ Плавное и естественное замедление
✅ Игрок видит, что его останавливают
✅ Нет резких рывков или глитчей
✅ Более приятный UX

ВРЕМЯ РЕСПАВНА:
- Плавное замедление: 0.5 секунды
- Пауза перед телепортацией: 0.1 секунды
- Пауза после телепортации: 0.1 секунды
- **ИТОГО: ~0.7 секунды** (вместо мгновенной блокировки)

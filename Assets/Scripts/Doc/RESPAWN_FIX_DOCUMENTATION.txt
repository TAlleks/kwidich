- Синусоида для плавного эффекта
- Использование Time.fixedDeltaTime

9. ТЕХНИЧЕСКИЕ ДЕТАЛИ
================================================================================

ПОЧЕМУ РАЗДЕЛИЛИ UPDATE И FIXEDUPDATE:

Update() - для логики и визуала:
- Вызывается каждый кадр (нестабильный интервал)
- Подходит для проверок, условий, вращения transform
- НЕ подходит для физики (rb.velocity, rb.AddForce)

FixedUpdate() - для физики:
- Вызывается с фиксированным интервалом (обычно 50 раз/сек)
- Синхронизирован с физическим движком Unity
- ОБЯЗАТЕЛЕН для работы с Rigidbody

ПРАВИЛО:
- Все изменения rb.linearVelocity, rb.angularVelocity, rb.AddForce
  должны быть в FixedUpdate()
- Все изменения transform.position, transform.rotation, transform.Rotate
  могут быть в Update()
